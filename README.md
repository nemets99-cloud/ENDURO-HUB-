# ENDURO HUB

Мобильное приложение для эндуро на React Native + Expo.

## Реализовано

- Тёмный главный экран в эндуро-стилистике
- GPS-карта с текущим местоположением
- Запись маршрута по GPS с отрисовкой линии на карте
- Фоновая запись GPS через Expo TaskManager и Android foreground service
- Сохранение активного трека между перезапусками интерфейса
- Расчёт пройденного расстояния и времени поездки
- Сохранение последних 30 поездок локально на телефоне
- Просмотр сохранённого GPS-трека
- Экспорт сохранённых поездок в GPX и отправка через меню Android

## Запуск на Android

1. Установи Node.js LTS.
2. В корне проекта выполни `npm install`.
3. Выполни `npx expo install --fix`, чтобы Expo подобрал совместимые версии модулей.
4. Для обычного просмотра интерфейса запусти `npx expo start`.
5. Для фоновой GPS-записи собери и установи отдельный Android APK через EAS Build: `npx eas build -p android --profile preview`. Expo Go на Android не поддерживает фоновую задачу геолокации.

Для сборки Android-приложения можно использовать EAS Build. Фоновая геолокация требует новой нативной сборки после изменения разрешений и конфигурации.

## Разрешения и ограничения

- При первом открытии карты приложение запросит доступ к геолокации.
- Для записи маршрута нужны разрешения на геолокацию «При использовании» и «Всегда»; Android может перенаправить в настройки для выдачи фонового доступа.
- Во время фоновой записи Android показывает постоянное системное уведомление о работе GPS-сервиса.
- Работа в фоне зависит от ограничений Android и настроек энергосбережения производителя. Принудительное завершение приложения может остановить запись.
- Фоновая запись не работает в Expo Go на Android; требуется установленная сборка приложения.
- Поездки и GPX-файлы обрабатываются локально на устройстве; облачной синхронизации нет.
- Для экспорта открой список сохранённых поездок и нажми кнопку «GPX» рядом с нужным маршрутом.
- Для отображения карт требуется интернет; доступность карт зависит от провайдера и региона.
- Проверяй местные правила движения по бездорожью и не используй телефон во время езды.
