# ENDURO HUB

Стартовый проект мобильного приложения для эндуро на React Native + Expo.

## Что уже есть

- Главный экран в тёмной эндуро-стилистике
- Разделы: маршруты, дневник поездок, гараж и обслуживание
- Карточки быстрых действий
- Адаптация под Android и iOS

## Запуск

1. Установите Node.js LTS.
2. В корне проекта выполните `npm install`.
3. Запустите `npx expo start`.
4. Откройте проект через Expo Go или запустите Android-эмулятор.

## Ближайший план

1. Добавить регистрацию и профиль райдера.
2. Реализовать запись GPS-треков и сохранение маршрутов.
3. Добавить мотоциклы, моточасы и журнал обслуживания.
4. Подключить карты и обмен маршрутами.

Это начальный каркас интерфейса. GPS, карты, авторизация и облачное хранение пока не подключены.
